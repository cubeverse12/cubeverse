MINEVORA / POMOC

Centrum pomocy.

Najważniejsze informacje dotyczące pobierania i uruchamiania.

Jak pobrać launcher?

Przejdź do zakładki „Pobierz launcher” i pobierz archiwum ZIP. Rozpakuj je, a następnie uruchom diagnostykę i skrypt startowy.

Czy strona WWW zastępuje aplikację Windows?

Nie. Publiczna strona służy do prezentacji projektu i pobierania programu. Zaawansowane funkcje pozostają w aplikacji MINEVORA dla Windows.

Czy potrzebuję Pythona?

Tak. Udostępniana paczka zawiera pliki źródłowe Pythona. Na wcześniej testowanym komputerze działa Python 3.15 z PySide6 i biblioteką minecraft-launcher-lib.

Czy GitHub Pages działa, kiedy komputer jest wyłączony?

Tak. Po publikacji GitHub Pages udostępnia stronę z serwerów hostingu niezależnie od Twojego komputera. Dostępność zależy od usługi GitHub Pages.
