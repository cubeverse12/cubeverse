O MINEVORA

Launcher tworzony z pasją

MINEVORA to niezależna aplikacja desktopowa rozwijana w Pythonie, z interfejsem PySide6. Jej celem jest wygodny dostęp do legalnie posiadanej gry Minecraft Java Edition oraz zarządzanie wersjami i dodatkami.

Logowanie kontem Microsoft wymaga odpowiednich uprawnień API. Projekt nie omija weryfikacji kont ani licencji.
