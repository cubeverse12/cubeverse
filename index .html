O MINEVORA

Launcher tworzony z pasją

MINEVORA to niezależna aplikacja desktopowa rozwijana w Pythonie, z interfejsem PySide6. Jej celem jest wygodny dostęp do legalnie posiadanej gry Minecraft Java Edition oraz zarządzanie wersjami i dodatkami.

O MINEVORA

Niezależny projekt desktopowy

MINEVORA Launcher to aplikacja rozwijana w języku Python, wykorzystująca interfejs Qt (PySide6). Jej celem jest umożliwienie legalnego uruchamiania Minecraft Java Edition przez użytkowników posiadających odpowiednią licencję.

Projekt nie omija logowania, weryfikacji licencji ani mechanizmów bezpieczeństwa. Funkcjonalność uwierzytelniania Microsoft jest obecnie przygotowywana i oczekuje na odpowiednie uprawnienia API.

Status: w rozwoju. Publiczny instalator nie jest jeszcze udostępniony na tej stronie.

Informacje prawne

MINEVORA jest nieoficjalnym, niezależnym projektem. Nie jest zatwierdzony, sponsorowany ani powiązany z Microsoft, Mojang Studios lub Xbox. Minecraft jest znakiem towarowym odpowiednich właścicieli. Użytkownicy muszą posiadać uprawnienia do korzystania z Minecraft Java Edition.
