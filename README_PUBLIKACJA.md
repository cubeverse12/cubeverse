# MINEVORA WEB 17.5 — instrukcja

## Zawartość
- `index.html`, `styles.css`, `app.js` — strona
- `skin3d.js` — lokalny edytor 3D z zapisem PNG
- `mods.js` — wyszukiwarka katalogu Modrinth, otwiera stronę projektu
- `assets/` — lokalne grafiki i ikony
- `downloads/MINEVORA_17_4_AUDYT_NAPRAWIONE.zip` — działająca wersja projektu z rozmowy
- `.nojekyll` — wyłącza zbędne przetwarzanie

## GitHub Pages (publiczna strona bez własnego komputera)
1. Na GitHub otwórz repozytorium (publiczne dla konta GitHub Free).
2. Wgraj **pliki i foldery z wnętrza tej paczki** do głównego katalogu repozytorium. `index.html` musi być bezpośrednio w repozytorium.
3. Wejdź w `Settings → Pages → Build and deployment → Deploy from a branch`.
4. Wybierz gałąź `main`, folder `/(root)`, kliknij Save.
5. Po opublikowaniu kliknij `Visit site` na stronie ustawień Pages.

**Uwaga:** Nie można zagwarantować 100% uptime hostingu ani zewnętrznego Modrinth API. Strona nie została opublikowana na Twoim koncie GitHub. Wersja HTML jest statyczna — logowanie do Minecrafta i instalacja modów działa w launcherze Windows, nie w przeglądarce.
