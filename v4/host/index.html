MINEVORA / HOST 0.9.7

Twój serwer. Twój komputer.

MINEVORA HOST 0.9.7 to osobny panel do lokalnego zarządzania serwerami Minecraft Java na Windows. Możesz sprawdzać stan instancji, przygotowywać Vanilla, zarządzać światami, kopiami zapasowymi i diagnostyką. To narzędzie do lokalnych testów, nie publiczna usługa hostingowa.

WindowsHOST 0.9.7Panel: 127.0.0.1:8000Agent: 127.0.0.1:8767
Panel lokalny · stan niezweryfikowany

Strona nie sprawdza, czy panel i agent są uruchomione. Otwórz adres na komputerze, na którym działa HOST.

Otwórz lokalny panel HOST Podgląd gościa Launcher Windows

Panel otworzy się wyłącznie wtedy, gdy MINEVORA HOST działa na tym samym urządzeniu. Na telefonie adres 127.0.0.1 wskazuje telefon, a nie komputer Windows.

LOKALNE FUNKCJE

Panel zarządzania Minecraft Java

HOST zachowuje oddzielne logowanie operatora i kontrolę lokalnego agenta. Strona minevora.pl nie pobiera danych z panelu, haseł ani tokenów.

Serwery i instancje

Zarządzaj lokalnymi instancjami i sprawdzaj ich stan z poziomu panelu HOST.

Światy i kopie

Przechowuj światy oddzielnie, wykonuj kopie zapasowe i korzystaj z kontroli bezpiecznej aktualizacji.

Vanilla i dodatki

Wybierz zgodną wersję serwera; pluginy Paper i mody Fabric wymagają odpowiedniego silnika, nie Vanilla.

Stan i diagnostyka

Sprawdzaj informacje o serwerze, lokalnego agenta i komunikaty diagnostyczne.

URUCHOMIENIE HOST

Uruchom w trzech krokach

KROK 01

Wybierz instalację

HOST jest osobnym programem. Wskaż istniejący folder 0.9.7 albo przygotuj nową oddzielną kopię. Zakładka HOST w UI26 jest demonstracją. Nie nadpisuj folderu ze światami.

KROK 02

Włącz panel i agenta

Uruchom panel i agenta w osobnych oknach Windows. Panel używa portu 8000, a agent portu 8767, tylko lokalnie.

KROK 03

Zaloguj operatora

Otwórz panel na tym samym komputerze, zaloguj się na konto operatora i wybierz instancję serwera. Uprawnienia pozostają po stronie HOST.

Bezpieczeństwo i ograniczenia

Nie udostępniaj publicznie portów 8000 ani 8767. Nie uruchamiaj panelu na internetowym serwerze bez osobnej architektury bezpieczeństwa. HOST 0.9.7 nie gwarantuje publicznych adresów, automatycznej ochrony DDoS ani dostępności 24/7.
