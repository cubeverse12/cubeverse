MINEVORA / POMOC WINDOWS

Instalacja launchera krok po kroku.

Jak zacząć z Minecraft Java, własnymi profilami, modami i Skin Studio. Poradnik uwzględnia projekt MINEVORA 3.0.25 oraz różnice między nim a publicznymi wydaniami GitHub.

01 / START

Instalacja w 3 krokach

01

Pobierz ZIP

Otwórz publiczne wydania GitHub i wybierz właściwy plik. Sprawdź numer wersji.

02

Rozpakuj

Wybierz nowy folder. Zapoznaj się z dołączonym README i wymaganiami.

03

Uruchom

Otwórz skrypt startowy wskazany w README (w projekcie 3.x: START_WINDOWS.bat), wybierz profil i zaloguj konto.

Uwaga o wersjach: projekt 3.0.25 nie jest jeszcze publicznym wydaniem w GitHub Releases. W chwili aktualizacji strony najnowsze znalezione tam wydanie to 18.3.7. Instrukcja i nazwa skryptu w starszych wydaniach mogą się różnić.
02 / SYSTEM

Wymagania

Wersja desktopowa jest przygotowana dla Windows i Minecraft Java Edition. Pakiety zawierające kod Pythona mogą wymagać zainstalowanego Pythona oraz bibliotek opisanych w README. Do uruchamiania samej gry potrzebne są odpowiednia wersja Java i legalne konto Minecraft.

Jeśli instalator bibliotek nie zadziała, uruchom skrypt z katalogu projektu i przeczytaj pełny komunikat. W wersji 3.0.25 przydatne są także przyciski Diagnostyka oraz Ostatnie błędy; raport diagnostyczny nie powinien zawierać poufnych danych. Nie zmieniaj zabezpieczeń Windows w celu obejścia blokady niezweryfikowanego programu.

03 / KONTO

Logowanie Microsoft

Otwórz w launcherze zakładkę Konto i wybierz logowanie Microsoft. Przejdź do przeglądarki, zaloguj się na właściwe konto i wróć do programu po zakończeniu autoryzacji.

W wersjach korzystających z własnej rejestracji aplikacji Microsoft Entra ustaw Client ID i dokładny adres przekierowania zgodny z konfiguracją aplikacji, np. http://localhost:8765/callback. Nie jest to adres do otwierania ręcznie przed rozpoczęciem logowania.

Chroń konto: nie podawaj nikomu hasła, kodów z przeglądarki, tokenów ani pełnych adresów z parametrem code. Nie wklejaj ich na Discord ani do zgłoszeń.
04 / WYGLĄD

Violet Premium — motywy i animacje

W MINEVORA 3.0.25 wejdź w Ustawienia → Wygląd i płynność, aby wybrać Violet Neon lub Violet Soft, włączyć kompaktowe karty instancji i ograniczyć animacje. Wybór jest zapisywany lokalnie w ustawieniach programu.

Przełączniki motywów na stronie MINEVORA służą wyłącznie do demonstracji wyglądu. Nie zmieniają ustawień instalowanego programu ani konta Minecraft.

05 / PVP HUD 2.0.15

Jak włączyć PvP Mode w Minecraft?

Nowe wydanie MINEVORA PvP HUD 2.0.15 jest dostępne osobno dla Fabric 1.21.1. Dodaje serduszka nad graczami oraz przesuwane kafelki CPS, FPS, Combo, mikstur i pancerza. Nie jest jeszcze potwierdzone, że launcher 3.0.25 automatycznie pobiera tę aktualizację.

01

Wybierz Fabric

Wybierz profil Minecraft Java 1.21.1 z Fabric Loader i Fabric API. Potrzebujesz Java 21. Nie instaluj tego pliku w Vanilla, Forge, NeoForge ani w innych wersjach Minecraft.

02

Pobierz PvP HUD 2.0.15

Pobierz oficjalny plik JAR z GitHub Releases, zamknij grę i umieść plik w folderze mods używanym przez wybraną instancję. Jeśli znajduje się tam starszy MINEVORA PvP HUD, usuń starszą wersję przed uruchomieniem gry.

03

Otwórz menu i ustaw HUD

Wejdź do świata Minecraft i naciśnij prawy Shift lub P, aby otworzyć menu moda. Wybierz HUD → PRZESUŃ KAFELKI, przeciągnij moduły i kliknij Gotowe. Klawisz H ukrywa lub pokazuje HUD.

Serduszka nad graczami: działają w pobliżu innych widocznych postaci, ale ich dokładność zależy od informacji o HP, które udostępnia serwer. Ułożenie kafelków zapisuje się w konfiguracji moda. Pokaz na stronie jest tylko interaktywną makietą, nie steruje ustawieniami Minecraft.

Pobierz i sprawdź wydanie PvP HUD 2.0.15 na GitHub.

06 / BIBLIOTEKA

Modrinth, CurseForge i modpacki

Wybierz instancję Minecraft, następnie kategorię: Mody, Modpacki, Shadery, Resource Packi albo Datapacki. Filtruj wyniki według wersji gry i loadera, zanim zainstalujesz dodatek.

Nie wszystkie mody działają na każdej wersji Minecraft; Fabric i Forge mają różne wymagania. Datapack należy przypisać do konkretnego świata. Pełna integracja CurseForge może wymagać klucza API zapisanego lokalnie w launcherze.

07 / POMOC

Najczęstsze pytania

Dlaczego strona oferuje starszy ZIP niż 3.0.25?

Witryna przedstawia projekt 3.0.25, ale najnowsza paczka nie została jeszcze dodana do GitHub Releases. Link pobierania prowadzi do prawdziwych publicznych wydań, a nie do nieistniejącego instalatora.

Launcher nie uruchamia się. Co sprawdzić?

Sprawdź, czy uruchamiasz skrypt z rozpakowanego folderu, czy Python i biblioteki są dostępne oraz czy w oknie konsoli pojawił się konkretny komunikat błędu. W razie potrzeby prześlij sam tekst błędu, bez danych logowania.

Po logowaniu Microsoft pojawia się błąd localhost.

Sprawdź, czy wersja launchera uruchamia lokalny odbiornik, czy port nie jest zajęty, a adres URI przekierowania w Entra dokładnie odpowiada konfiguracji aplikacji, łącznie z /callback. Nie udostępniaj URL zawierającego kod jednorazowy.

Czy PvP HUD działa na każdej wersji Minecraft?

Nie. PvP HUD 2.0.15 działa z Fabric 1.21.1. Inne wersje Minecraft i inne loadery wymagają osobnych zgodnych kompilacji.

Dlaczego mod nie instaluje się na mojej wersji?

Sprawdź wersję Minecraft, loader, zależności i rodzaj pliku. Nie każda modyfikacja jest zgodna ze wszystkimi wersjami lub loaderami.

Czy Skin Studio zmienia skina na koncie automatycznie?

Skin Studio edytuje i zapisuje skiny lokalnie. Funkcje konta Minecraft mogą wymagać osobnego kroku; nie należy zakładać, że sam eksport PNG ustawia skina na koncie.

08 / BEZPIECZEŃSTWO

Pobieraj ze sprawdzonych źródeł

Nie wyłączaj Microsoft Defender ani Smart App Control. Nie udostępniaj folderu z tokenami i sprawdzaj raporty przed przekazaniem ich innym osobom. Sprawdzaj źródło plików, licencje modów i adresy stron autoryzacji. Jeśli potrzebujesz pomocy, napisz na Discordzie MINEVORA, ale nigdy nie publikuj tokenów ani poufnych danych.
