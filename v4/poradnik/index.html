01 / INSTALACJA

Instalacja w trzech krokach

1

Pobierz projekt

Pobierz aktualny ZIP 19.0.3 z rozmowy projektu i rozpakuj go. GitHub Releases może nadal zawierać starsze publiczne wydanie.

2

Uruchom skrypt

W rozpakowanym folderze uruchom START_MINEVORA.bat. Skrypt przygotuje środowisko Python i wymagane biblioteki PySide6.

3

Wybierz profil i wersję

Przejdź do zakładki Graj, wybierz wersję Minecrafta i loader, sprawdź Javę i połącz konto Microsoft z uprawnieniem do Minecraft Java Edition.

02 / PRZED STARTEM

Co jest potrzebne?

Windows 11, Python zgodny z wymaganiami, internet do pobrania bibliotek, odpowiednia Java i konto Microsoft z licencją Minecraft Java. Przy pierwszym uruchomieniu PySide6 może pobierać duże pakiety.

Diagnostykę uruchomisz z DIAGNOSTYKA.bat. Nie wyłączaj zabezpieczeń Windows, aby uruchomić nieznany plik.

03 / KONTO MICROSOFT

Bezpieczne logowanie

Logowanie powinno używać oficjalnej autoryzacji Microsoft. Dla tego projektu wymagane jest poprawne skonfigurowanie OAuth Client ID i Redirect URI. Nie wprowadzaj hasła Microsoft w nieznane formularze i nikomu nie udostępniaj tokenów.

04 / FAQ

Najczęstsze pytania

Program nie otwiera okna. Co zrobić?

Uruchom DIAGNOSTYKA.bat. Jeśli wystąpi Traceback, skopiuj komunikat błędu. Nie wysyłaj tokenów ani kodów logowania.

Dlaczego PySide6 pobiera tak dużo plików?

PySide6 i moduły Qt WebEngine zawierają duże biblioteki. Pobieranie może być długie, szczególnie podczas pierwszej instalacji.

Czy ZIP jest gotowym plikiem EXE?

Nie. Wersja 19.0.3 jest projektem źródłowym uruchamianym przez skrypt BAT.

Czy minigry, Marketplace i PvP HUD działają w grze?

Moduły online i integracja PvP HUD z Minecraftem są nadal w przygotowaniu. Podglądy na stronie nie uruchamiają gry.

Dlaczego GitHub pokazuje starszą wersję?

Nowa paczka źródłowa 19.0.3 została przygotowana oddzielnie. Lista publicznych wydań może jeszcze pokazywać starszy numer, dopóki nie zostanie opublikowane nowe wydanie.

05 / BEZPIECZEŃSTWO

Sprawdzaj źródło plików

Pobieraj pliki tylko z zaufanego źródła. Nie wyłączaj Microsoft Defender ani Windows Smart App Control. Weryfikuj adresy logowania i nie udostępniaj kodów jednorazowych.
