MINEVORA / PORADNIK WINDOWS

Minecraft Java.
Od pierwszego uruchomienia.

Praktyczny przewodnik dla MINEVORA 1.56.17: uruchomienie na Windows, konto Microsoft, mody, datapacki, shadery, serwery i diagnostyka.

01 / INSTALACJA

Uruchom launcher w trzech krokach

  1. 01

    Pobierz

    Na stronie Pobierz sprawdź dostępne wydania. Wybierz ZIP pasujący do Windows i przeczytaj opis.

  2. 02

    Rozpakuj

    Wypakuj cały ZIP do nowego folderu, razem z podfolderami i plikami .bat. Nie uruchamiaj programu bezpośrednio z archiwum.

  3. 03

    Zainstaluj i uruchom

    Dla paczki testowej 1.56.17 uruchom kolejno: 01_INSTALUJ_15617.bat → 02_SPRAWDZ_15617.bat → 03_URUCHOM_15617.bat. W innych wydaniach korzystaj z README dołączonego do paczki.

Jeśli instalacja nie powiedzie się, odczytaj komunikat w terminalu. Nie wyłączaj Microsoft Defender i nie uruchamiaj skryptów pobranych z nieznanych źródeł.

02 / GRAJ

Pierwsze uruchomienie Minecrafta

Wybierz paczkę

Utwórz lub wybierz istniejący profil w „Moje paczki”.

Ustaw wersję i loader

Wybierz zgodną wersję Minecraft Java i Vanilla, Fabric, Forge, NeoForge lub Quilt.

Kliknij GRAJ

Launcher powinien przygotować profil, a następnie uruchomić grę. Uruchomienie na danym komputerze należy przetestować.

Nie zmieniaj wersji istniejącego świata bez kopii zapasowej. Wymagane biblioteki i Java zależą od wybranej wersji gry.

03 / MICROSOFT

Konto Microsoft — bezpieczne logowanie

W launcherze wybierz ikonę konta i uruchom oficjalny proces logowania Microsoft. Jeśli pojawi się kod urządzenia, użyj wyłącznie adresu podanego przez Microsoft. Nie wpisuj hasła bezpośrednio w oknie MINEVORA.

Do uruchamiania Minecraft Java wymagane jest konto z odpowiednimi uprawnieniami. Brak poprawnej konfiguracji aplikacji wydawcy może zablokować logowanie — sam Client ID nie jest gwarancją działania.

04 / MODRINTH

Przeglądaj i instaluj dodatki

ModyPliki JAR i zależności loadera ModpackiOsobne instancje Minecrafta DatapackiPliki konkretnego świata ShaderyEfekty graficzne ResourcepackiTekstury i zasoby gry

Przed instalacją sprawdź wersję Minecrafta i loader. Jeśli Modrinth wymaga dodatkowych modów, zatwierdź ich listę; nie pomijaj kontroli zależności. Gdy prawdziwa okładka jest niedostępna, launcher może pokazać ikonę zastępczą kategorii.

05 / MODPACKI

Oddzielne paczki, oddzielne światy

Użyj przycisku + w panelu paczek, aby utworzyć profil albo rozpocząć import obsługiwanego archiwum. Nadaj nazwę, ustaw Minecraft i loader. Każda paczka powinna przechowywać własne mody, konfigurację i światy.

Przed aktualizacją modpacka przygotuj kopię zapasową. Nie zamieniaj ręcznie plików paczki podczas działania gry.

06 / DATAPACKI

Datapack jest przypisany do świata

Wybierz paczkę i konkretny świat. Datapack ZIP zapisuje się w katalogu saves/NazwaŚwiata/datapacks — nie w głównym folderze mods. Świat musi istnieć, zanim dodasz do niego datapack.

Wykonaj kopię świata przed instalacją, a później sprawdź zawartość w grze.

07 / GRAFIKA

Shadery i paczki zasobów

Shadery

Pliki ZIP trafiają do shaderpacks. Do wyświetlania shaderów wymagany jest zgodny mod, na przykład Iris dla odpowiedniej konfiguracji Fabric.

Paczki zasobów

Pliki ZIP trafiają do resourcepacks. Włączysz je w ustawieniach zasobów Minecraft.

08 / PERSONALIZACJA

Skin Studio i PvP HUD

W Skin Studio możesz przeglądać i wgrywać obsługiwane skiny PNG. Przed zapisaniem sprawdź podgląd postaci.

Dołączony PvP HUD 2.0.15 jest przeznaczony dla Fabric 1.21.1. Nie zakładaj zgodności z innymi wersjami; wymagane są odpowiednie zależności i test w grze.

Od MINEVORA 1.56.13 R3 możesz przenieść pozycje kafelków do moda z zakładki PvP. Zamknij grę, wybierz profil Fabric 1.21.1 i ustaw skalę podglądu na 75–100%. Wyższa skala zostanie odrzucona zamiast zapisania innej wartości. W grze naciśnij prawy Shift lub P, aby otworzyć ustawienia; H ukrywa lub pokazuje HUD.

W wersji testowej R3 użyj przycisku „SPRAWDŹ PvP HUD W TEJ PACZCE”. Kontrola jest tylko do odczytu: sprawdza sumę SHA-256 moda, zgłasza uszkodzony lub zmieniony JAR oraz nie nadpisuje własnych plików.

09 / SERWERY I HOST

Serwery Minecraft oraz lokalny panel HOST

Lista serwerów

Dodaj adres serwera Minecraft Java w zakładce Serwery. Jeżeli nie pojawia się ikona, odśwież status i sprawdź połączenie; brak ikony nie oznacza automatycznie, że serwer nie działa.

MINEVORA HOST 0.9.7

HOST to oddzielny, lokalny panel Windows. Po jego uruchomieniu sprawdzisz go pod adresem 127.0.0.1:8000 na tym samym komputerze.

Strona minevora.pl nie uruchamia panelu na Twoim komputerze. HOST nie jest publiczną usługą hostingową i wymaga własnej konfiguracji.

10 / POMOC

Gdy coś nie działa

Szukaj w pytaniach i odpowiedziach.
Launcher nie startuje / błąd importu

Najpierw sprawdź logs/startup_error.log. Uruchom skrypt diagnostyczny dostępny w danej paczce, na przykład DIAGNOZA_STARTU.bat. Pokaż sam komunikat błędu, bez tokenów i danych konta.

Modrinth: brakuje obowiązkowych zależności

Sprawdź listę wymagań moda, wersję gry i loader. W razie niezgodności wybierz kompatybilną wersję dodatku. Nie instaluj niesprawdzonych plików ręcznie w celu obejścia błędu.

Nie widać ikon modów albo okładek

Sprawdź połączenie z Modrinth CDN i ponów pobieranie okładek. Pliki lokalne bez osadzonej ikony mogą być pokazywane z symbolem kategorii.

Brak wersji Minecraft

Sprawdź połączenie z oficjalnym manifestem wersji, wybierz poprawną wersję Release i w razie potrzeby użyj akcji GRAJ do instalacji gry.

Nie można zalogować Microsoft

Sprawdź konfigurację publicznej aplikacji Microsoft i wymagane uprawnienia. Nie udostępniaj kodu urządzenia, haseł ani tokenów.

Po aktualizacji ikony są stare, niewyraźne lub zniknęły

Użyj pełnej paczki 1.56.17 w nowym folderze; nie mieszaj jej plików z wcześniejszą wersją. Sprawdź, czy rozpakowały się wszystkie katalogi z ikonami, oraz uruchom 02_SPRAWDZ_15617.bat. Jeśli problem pozostanie, wyślij zrzut ekranu i raport, bez danych logowania.

HOST pokazuje „offline” lub nie otwiera panelu

Panel HOST jest osobnym programem. Najpierw uruchom go lokalnie, a potem sprawdź adres http://127.0.0.1:8000/. Sam launcher ani strona internetowa nie uruchamiają usługi w tle.

Mod albo shader nie działa po instalacji

Porównaj wersję Minecrafta, loader, wersję moda i jego wymagane biblioteki. Shadery wymagają zgodnej obsługi, np. Iris w konfiguracji Fabric. Nie zastępuj w ciemno plików swojej instancji.

11 / DANE

Nie trać światów i modów

Nowe wersje launchera rozpakowuj do osobnego folderu. Przed większą aktualizacją zrób kopię światów oraz własnych paczek. Naprawa interfejsu nie powinna wymagać kasowania katalogu saves, modyfikacji Minecrafta ani wyłączania ochrony Windows.
