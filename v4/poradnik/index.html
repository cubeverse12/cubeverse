01 / INSTALACJA

Uruchom launcher w trzech krokach

  1. 01

    Pobierz

    Na stronie Pobierz sprawdź dostępne wydania. Wybierz ZIP pasujący do Windows i przeczytaj opis.

  2. 02

    Rozpakuj

    Wypakuj cały ZIP do nowego folderu, razem z podfolderami i plikami .bat. Nie uruchamiaj programu bezpośrednio z archiwum.

  3. 03

    Zainstaluj i uruchom

    Rozpakuj ZIP UI26 do nowego folderu. Wykonaj kopię danych. Uruchom kolejno INSTALUJ.bat, TESTY_OFFLINE.bat i START_TESTOWY.bat albo skrypt SETUP_TESTOWY.bat, który wykonuje te trzy kroki. Nie wyłączaj zabezpieczeń Windows.

Jeśli instalacja nie powiedzie się, odczytaj komunikat w terminalu. Nie wyłączaj Microsoft Defender i nie uruchamiaj skryptów pobranych z nieznanych źródeł.

Instalacja UI26 krok po kroku

Wykonaj kopię światów i paczek przed instalacją.

  1. Kopia danych i nowy folderZIP → Windows
  2. Instalacja bibliotekINSTALUJ.bat
  3. Testy offlineTESTY_OFFLINE.bat
  4. Uruchomienie testoweSTART_TESTOWY.bat

Opcjonalnie: SETUP_TESTOWY.bat wykonuje wszystkie trzy skrypty automatycznie.

RC23 UI26 / WERYFIKACJA

Sprawdź RC23 UI26 przed uruchomieniem gry

Rozpakuj ZIP UI26 do nowego folderu. Wykonaj kopię danych. Uruchom kolejno INSTALUJ.bat, TESTY_OFFLINE.bat i START_TESTOWY.bat albo skrypt SETUP_TESTOWY.bat, który wykonuje te trzy kroki. Nie wyłączaj zabezpieczeń Windows.

Kontrola offline UI26: 436 plików Python bez błędów składni, 553 testy raportowane przez unittest w 52 zestawach (dwa przebiegi), 902 pozycje manifestu SHA-256 i 382 odczytane grafiki. Po ostatniej korekcie ponowiono dwa zestawy; wyniki nie zastępują testów Windows.

Logowanie Microsoft, start gry, pobieranie online i GUI Windows wymagają testów. CurseForge wymaga autoryzowanego klucza API, aktualizator wymaga klucza wydawcy, a właściwy JAR PvP HUD nie jest dołączony. Publiczna dostępność UI26 w GitHub Releases nie jest potwierdzona.

Aktualizacje i bezpieczeństwo

Weryfikator podpisów Ed25519 i SHA-256 jest przygotowany. Kanał aktualizacji wymaga konfiguracji przez wydawcę. Nie instaluj niepodpisanych aktualizacji ani nie udostępniaj prywatnego klucza.

Testy przed premierą

Sprawdź ekran ładowania, zmianę języka PL/EN, skalowanie 100%, 125% i 150% oraz automatyczne pobieranie zależności w izolowanej paczce Fabric.

Sprawdź logowanie Microsoft, rzeczywiste pobieranie Modrinth i CurseForge oraz uruchomienie gry. Zgłaszaj błędy bez haseł, tokenów, kluczy API i pełnych logów konta.

Zrób kopię światów i paczek. Nie udostępniaj haseł, tokenów ani kodów logowania Microsoft.

02 / GRAJ

Pierwsze uruchomienie Minecrafta

Układ ekranu GRAJ w R7 (zachowany w 1.56.19 R9): u góry są trzy działające pola wyboru — Wersja Minecraft, Loader oraz Profil / Instancja. Pod nimi znajduje się jeden duży przycisk GRAJ, a niżej sekcje Instancje i Dodatki i mody. Na węższych oknach wybory mogą układać się pionowo. Jest to zmiana wyglądu, nie mechanizmu instalacji ani uruchamiania gry.

Zobacz makietę układu R7 na stronie głównej. Makieta nie przedstawia rzeczywistego zrzutu ekranu Windows; start PySide6 i Minecrafta nadal wymagają testu na komputerze.

Wybierz paczkę

Utwórz lub wybierz istniejący profil w „Moje paczki”.

Ustaw wersję i loader

Wybierz zgodną wersję Minecraft Java i Vanilla, Fabric, Forge, NeoForge lub Quilt.

Kliknij GRAJ

Launcher powinien przygotować profil, a następnie uruchomić grę. Uruchomienie na danym komputerze należy przetestować.

Nie zmieniaj wersji istniejącego świata bez kopii zapasowej. Wymagane biblioteki i Java zależą od wybranej wersji gry.

03 / MICROSOFT

Konto Microsoft — bezpieczne logowanie

W launcherze wybierz ikonę konta i uruchom oficjalny proces logowania Microsoft. Jeśli pojawi się kod urządzenia, użyj wyłącznie adresu podanego przez Microsoft. Nie wpisuj hasła bezpośrednio w oknie MINEVORA.

Do uruchamiania Minecraft Java wymagane jest konto z odpowiednimi uprawnieniami. Brak poprawnej konfiguracji aplikacji wydawcy może zablokować logowanie — sam Client ID nie jest gwarancją działania.

04 / MODRINTH I CURSEFORGE

Przeglądaj i instaluj dodatki

Jak działa automatyczna naprawa modów?

1. Wybierz testową paczkę Fabric i zgodną wersję Minecraft.

2. Kliknij GRAJ. Launcher sprawdza wymagane zależności i próbuje pobrać rozpoznane biblioteki z Modrinth.

3. Po pobraniu następuje ponowna kontrola paczki. Przy konflikcie lub braku internetu sprawdź komunikat; nie usuwaj istniejących modów w ciemno.

Automatyczna naprawa przed startem dotyczy rozpoznanych zależności Fabric. Forge, NeoForge, Quilt i CurseForge nie są objęte tym mechanizmem. Rzeczywiste pobieranie wymaga testu na Windows.

Przed instalacją sprawdź wersję Minecrafta i loader. Jeśli Modrinth wymaga dodatkowych modów, zatwierdź ich listę; nie pomijaj kontroli zależności. Gdy prawdziwa okładka jest niedostępna, launcher może pokazać ikonę zastępczą kategorii.

CurseForge — testy BETA

Korzystaj wyłącznie z autoryzowanego klucza API i plików dopuszczonych do dystrybucji. Nie udostępniaj kluczy innym osobom. Sprawdź listę zależności przed instalacją; wykonaj kopię paczki.

05 / MODPACKI

Oddzielne paczki, oddzielne światy

Użyj przycisku + w panelu paczek, aby utworzyć profil albo rozpocząć import obsługiwanego archiwum. Nadaj nazwę, ustaw Minecraft i loader. Każda paczka powinna przechowywać własne mody, konfigurację i światy.

Import ZIP CurseForge jest eksperymentalny. Użyj IMPORT_CURSEFORGE.bat i nowego katalogu. Następnie ręcznie skonfiguruj zgodny loader i profil; nie mieszaj plików z innymi paczkami.

Przed aktualizacją modpacka przygotuj kopię zapasową. Nie zamieniaj ręcznie plików paczki podczas działania gry.

06 / DATAPACKI

Datapack jest przypisany do świata

Wybierz paczkę i konkretny świat. Datapack ZIP zapisuje się w katalogu saves/NazwaŚwiata/datapacks — nie w głównym folderze mods. Świat musi istnieć, zanim dodasz do niego datapack.

Wykonaj kopię świata przed instalacją, a później sprawdź zawartość w grze.

07 / GRAFIKA

Shadery i paczki zasobów

Shadery

Pliki ZIP trafiają do shaderpacks. Do wyświetlania shaderów wymagany jest zgodny mod, na przykład Iris dla odpowiedniej konfiguracji Fabric.

Paczki zasobów

Pliki ZIP trafiają do resourcepacks. Włączysz je w ustawieniach zasobów Minecraft.

08 / PERSONALIZACJA

Skin Studio

W Skin Studio możesz przeglądać i wgrywać obsługiwane skiny PNG. Przed zapisaniem sprawdź podgląd postaci i wybierz odpowiedni typ ramion.

Wybierz skina

Skorzystaj z biblioteki lub zaimportuj plik PNG 64×64.

Sprawdź model

Obróć postać w podglądzie i sprawdź, jak wygląda tekstura.

Zapisz

Zapisuj własne zmiany lokalnie i zachowaj kopię oryginalnej skórki.

09 / PVP HUD

Instalacja i ustawienia PvP HUD 2.0.15

W RC23 UI26 brakuje właściwego JAR-a PvP HUD. Nie pobieraj przypadkowych zamienników. Przywrócenie oryginalnego pliku umożliwia PRZYWROC_PVP.bat; działanie w grze wymaga testu.

Ten mod jest przeznaczony dla Minecraft Java 1.21.1 z Fabric. Potrzebujesz zgodnego Fabric Loader, Fabric API oraz Java 21. Nie zakładaj zgodności z innymi wersjami gry lub loaderami.

  1. 01

    Sprawdź profil

    W launcherze wybierz istniejącą instancję Fabric 1.21.1. Upewnij się, że gra jest zamknięta, zanim zmienisz pliki moda.

  2. 02

    Zweryfikuj moda

    W zakładce PvP użyj kontroli zgodności i integralności dostępnej w swojej paczce. Jeżeli zgłasza błąd, nie traktuj instalacji jako zakończonej.

  3. 03

    Ustaw HUD

    W grze prawy Shift lub P otwiera ustawienia, a H ukrywa albo pokazuje HUD. Rozmieszczenie kafelków sprawdź w działającej grze.

W wydaniach obsługujących eksport układu z zakładki PvP można przenieść pozycje kafelków do moda. Zamknij grę, użyj profilu Fabric 1.21.1 i skali podglądu 75–100%. Wyższe wartości nie są obsługiwane przez ten eksport.

PvP HUD 2.0.15 to osobny plik JAR, a nie instalator launchera. Testy w rzeczywistym Minecrafcie i na koncie użytkownika muszą zostać wykonane na Windows.

Serwery Minecraft oraz lokalny panel HOST

MINEVORA HOST 0.9.7

HOST to oddzielny, lokalny panel Windows. Po jego uruchomieniu sprawdzisz go pod adresem 127.0.0.1:8000 na tym samym komputerze.

Strona minevora.pl nie uruchamia panelu na Twoim komputerze. HOST nie jest publiczną usługą hostingową i wymaga własnej konfiguracji.

11 / POMOC

Gdy coś nie działa

Szukaj w pytaniach i odpowiedziach.
Launcher nie startuje / błąd importu

Najpierw sprawdź logs/startup_error.log. Uruchom skrypt diagnostyczny dostępny w danej paczce, na przykład DIAGNOZA_STARTU.bat. Pokaż sam komunikat błędu, bez tokenów i danych konta.

Modrinth: brakuje obowiązkowych zależności

Sprawdź listę wymagań moda, wersję gry i loader. W razie niezgodności wybierz kompatybilną wersję dodatku. Nie instaluj niesprawdzonych plików ręcznie w celu obejścia błędu.

Nie widać ikon modów albo okładek

Sprawdź połączenie z Modrinth CDN i ponów pobieranie okładek. Pliki lokalne bez osadzonej ikony mogą być pokazywane z symbolem kategorii.

Brak wersji Minecraft

Sprawdź połączenie z oficjalnym manifestem wersji, wybierz poprawną wersję Release i w razie potrzeby użyj akcji GRAJ do instalacji gry.

Nie można zalogować Microsoft

Sprawdź konfigurację publicznej aplikacji Microsoft i wymagane uprawnienia. Nie udostępniaj kodu urządzenia, haseł ani tokenów.

Po aktualizacji ikony są stare, niewyraźne lub zniknęły

Użyj pełnej paczki 1.56.19 w nowym folderze; nie mieszaj jej plików z wcześniejszą wersją. Sprawdź, czy rozpakowały się wszystkie katalogi z ikonami, oraz uruchom 02_SPRAWDZ_15619.bat. Jeśli problem pozostanie, wyślij zrzut ekranu i raport, bez danych logowania.

Kontrola 02_SPRAWDZ_15619.bat nie działa lub zatrzymuje się na testach

Użyj kompletnej paczki 1.56.19 R2 rozpakowanej do nowego folderu. R2 usuwa odwołanie do nieistniejącego testu i zawiera poprawiony README. Uruchom kontrolę ponownie; jeśli zgłasza błąd SHA-256, nie nadpisuj pojedynczych plików — rozpakuj pełne, sprawdzone archiwum. Testy offline nie zastępują uruchomienia gry na Windows.

Nowa diagnostyka startu w 1.56.19 R3

Jeśli launcher nie otwiera się na Windows, uruchom 04_DIAGNOZA_15619_R3.bat z pełnej paczki R3. Narzędzie sprawdza podstawowe pliki i biblioteki bez otwierania Minecrafta. Jeśli błąd pochodzi z lokalnego modułu, raport może pokazać jego nazwę i numer wiersza, bez pełnych ścieżek, haseł i tokenów. Testy offline nie potwierdzają działania GUI ani logowania Microsoft.

R4: błąd importu funkcji lub klasy pomimo obecności pliku

W paczce 1.56.19 R4 uruchom 05_SPRAWDZ_IMPORTY_15619_R4.bat albo standardowe 02_SPRAWDZ_15619.bat. Analizator sprawdza wymagane nazwy w pięciu kluczowych modułach bez importowania Qt i bez danych konta. W razie błędu rozpakuj pełną paczkę R4 do osobnego folderu; nie mieszaj plików z innych wersji. Test statyczny nie zastępuje uruchomienia GUI na Windows.

R5: brak ikon Dodaj lub statusu serwera

W pełnej paczce 1.56.19 R5 poprawiono mapowanie nazw standardowych ikon na pliki SVG i dodano ikonę zastępczą dla brakującej grafiki programu. Użyj pełnego ZIP-a w nowym folderze i uruchom 06_SPRAWDZ_ZASOBY_15619_R5.bat. Kontrola weryfikuje 46 par SVG/PNG, aliasy i lokalne importy. Nie usuwa skinów, logo serwerów ani okładek modpacków.

R7: dlaczego wygląd ekranu GRAJ różni się od obrazka?

W R7 zmieniono położenie istniejących kontrolek Qt: Wersja Minecraft, Loader i Profil / Instancja znajdują się nad centralnym przyciskiem GRAJ. Kafelki Instancje oraz Dodatki i mody są poniżej. Obraz na stronie to schematyczny podgląd oparty na kodzie, nie wykonany zrzut aplikacji. Sprawdź rzeczywiste okno na Windows, a błędy zgłaszaj ze zrzutem i bez danych logowania. Możesz uruchomić kontrolę offline 08_SPRAWDZ_WYGLAD_15619_R7.bat; nie dowodzi ona poprawnego renderowania GUI.

R9 BETA: dlaczego 94 testy przechodzą, ale historyczne testy mają błędy?

09_TESTY_STARTU_R9.bat sprawdza aktualne krytyczne scenariusze, m.in. instalację gry z poprawnymi metadanymi JSON/JAR oraz wykrywanie uszkodzonych plików. Starszy zestaw obejmuje także testy dawnych wersji, niezgodne z R9. W ostatnim audycie pełnych źródeł wykonano 1024 testy: 218 niepowodzeń i 5 błędów. Do wydania stabilnego konieczne są dalsze poprawki i testy rzeczywistego Windows.

Gdzie jest instalator EXE wersji 1.56.19 R9?

R9 udostępniono w rozmowie jako pełny ZIP z kodem Python, nie jako EXE/MSIX ani potwierdzone wydanie GitHub Releases. Publiczne pobrania w serwisie GitHub mogą mieć inny numer wersji; zawsze sprawdzaj nazwę i opis pliku. Uruchamiaj wyłącznie pliki z zaufanego źródła.

HOST pokazuje „offline” lub nie otwiera panelu

Panel HOST jest osobnym programem. Najpierw uruchom go lokalnie, a potem sprawdź adres http://127.0.0.1:8000/. Sam launcher ani strona internetowa nie uruchamiają usługi w tle.

Mod albo shader nie działa po instalacji

Porównaj wersję Minecrafta, loader, wersję moda i jego wymagane biblioteki. Shadery wymagają zgodnej obsługi, np. Iris w konfiguracji Fabric. Nie zastępuj w ciemno plików swojej instancji.

12 / DANE

Nie trać światów i modów

Nowe wersje launchera rozpakowuj do osobnego folderu. Przed większą aktualizacją zrób kopię światów oraz własnych paczek. Naprawa interfejsu nie powinna wymagać kasowania katalogu saves, modyfikacji Minecrafta ani wyłączania ochrony Windows.
