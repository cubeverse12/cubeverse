AKTUALIZACJA PROJEKTU · 25.11.2026

MINEVORA 1.57.0 RC23 UI26 · testy zamknięte

RC23 UI26 udoskonala walidację wersji i loaderów, kontrolki, pamięć podręczną ikon, kamerę Skin Studio, podgląd PvP oraz diagnostykę uruchamiania. To wydanie źródłowe do zamkniętych testów Windows, nie podpisany instalator EXE/MSIX.

Inteligentne zależności Fabric

Przed startem gry launcher wykrywa rozpoznane brakujące biblioteki Fabric i dobiera zgodne wersje z Modrinth. RC23 UI26 sprawdza alternatywne zestawy, maksymalnie 24 próby pobrania kandydatów. Nie nadpisuje istniejących modów. Nieznane zależności wymagają ręcznej instalacji.

Ekran ładowania i stabilność

Pięć etapów uruchamiania, poprawki obsługi błędów, zabezpieczenia kopii i importu paczek, równe ikony 22 × 22 px oraz dopasowanie okna do monitorów.

Interfejs i Dodatki

Modrinth: kontrola zgodności wersji i zależności. CurseForge: autoryzacja CDN, zależności i eksperymentalny import ZIP.

Serwery

Wyszukiwanie, sortowanie, logotypy i zachowanie wyników po błędzie sieci.

Skin Studio

Modele Classic/Slim, import PNG, biblioteka i bezpieczniejszy zapis.

Kontrola offline UI26: 436 plików Python bez błędów składni, 553 testy raportowane przez unittest w 52 zestawach (dwa przebiegi), 902 pozycje manifestu SHA-256 i 382 odczytane grafiki. Po ostatniej korekcie ponowiono dwa zestawy; wyniki nie zastępują testów Windows.

Logowanie Microsoft, start gry, pobieranie online i GUI Windows wymagają testów. CurseForge wymaga autoryzowanego klucza API, aktualizator wymaga klucza wydawcy, a właściwy JAR PvP HUD nie jest dołączony. Publiczna dostępność UI26 w GitHub Releases nie jest potwierdzona.

Instrukcja testów RC23 UI26
01 / MOŻLIWOŚCI

Funkcje launchera w szczegółach

Każda funkcja ma własny ekran w aplikacji. Biblioteka dodatków, instalacje, edycja skina i zarządzanie profilami nie muszą być osobnymi programami.

01

Start i profile

Oddzielne instancje, wybór wersji Minecraft Java, kopie zapasowe, ulubione, przejrzystsze karty i kompaktowy układ.

02

Mody i modpacki

Katalog Modrinth, instalowanie zgodnych modów i paczek oraz kontrola zależności. Inne integracje są w trakcie rozwoju.

03

Shadery i paczki

Shadery, resource packi i datapacki w osobnych kategoriach, przypisane do właściwych profili i światów.

04

Skin Studio 3D

Obracany podgląd postaci, biblioteka skinów, import i eksport PNG oraz modele Classic/Slim.

05

Konto Microsoft

Logowanie Microsoft kodem urządzenia. Wymaga poprawnej konfiguracji aplikacji wydawcy i testów na Windows.

06

PvP Studio i HUD 2.0.15

Planowane serduszka nad graczami i przesuwane kafelki FPS, CPS, Combo, mikstur i pancerza. Właściwy plik JAR nie jest dołączony do RC23 UI26.

07

Diagnostyka i naprawa

Kontrola plików Minecraft, raporty błędów i pomoc w przywracaniu sprawności instancji.

08

Przywracanie profili

Odzyskiwanie usuniętych instancji ze światami i modami, bezpieczniejsze zarządzanie profilami.

02 / PVP STUDIO · MOD 2.0.15

PvP HUD ustawiony po Twojemu.

Docelowy PvP HUD 2.0.15 dla Fabric 1.21.1 przewiduje serca nad graczami i przesuwane kafelki. RC23 UI26 nie zawiera właściwego JAR-a; podgląd poniżej jest demonstracją strony.

Serduszka nad graczami — widoczne nad innymi postaciami w pobliżu. Dokładność HP zależy od danych przekazywanych przez serwer.
Przesuwane kafelki — osobno ustaw Armor HUD, FPS, CPS, Combo i efekty mikstur. Pozycje zapisują się w konfiguracji moda.
Prawy Shift / P — otwiera menu ustawień. H — ukrywa lub pokazuje HUD. Edytor pozycji znajdziesz w zakładce HUD.
Minecraft Java 1.21.1Fabric LoaderFabric APIJava 21
Instrukcja i status PvP HUD ↗

To osobny JAR moda Fabric 1.21.1, nie instalator launchera. Wymagane są Fabric API i Java 21+. Synchronizacja układu z launchera do moda obsługuje skalę 75–100%; większa skala podglądu nie jest eksportowana.
