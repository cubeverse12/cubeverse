MINEVORA 1.56.13 — Ciemny Łupek

Ujednolicamy wygląd launchera i strony. Widoki paczek, dodatków oraz serwerów zachowują swoje funkcje, a ikony otrzymują subtelniejszy cień. Aktywna ikona nie ma już pionowego paska wyboru.

Ikony i nawigacja

Nowy wspólny styl ikon kategorii, wyraźny stan aktywnych przycisków oraz poprawiony kontrast.

Serwery Minecraft

Launcher próbuje odczytać oryginalne logo serwera Java po bezpośrednim sprawdzeniu statusu; gdy brak odpowiedzi, pokazuje inicjały.

Mody i datapacki

Katalog Modrinth oraz instalacja datapacków do wybranego świata pozostają osobnymi, rzeczywistymi funkcjami.

To opis wydania rozwojowego. Pliki dla Windows są testowane osobno; na stronie pobierania sprawdzaj faktycznie opublikowaną wersję. Archiwalne wydania nie są już pokazywane na stronie głównej.

02 / PVP STUDIO · MOD 2.0.15

PvP HUD ustawiony po Twojemu.

Nowe MINEVORA PvP HUD 2.0.15 dla Minecraft Fabric 1.21.1 wyświetla serca nad postaciami i pozwala rozmieszczać kafelki tak, aby nie zasłaniały gry. Dołączony mod w launcherze obsługuje Fabric 1.21.1; działanie w grze wymaga testu.

♥Serduszka nad graczami — widoczne nad innymi postaciami w pobliżu. Dokładność HP zależy od danych przekazywanych przez serwer.
✥Przesuwane kafelki — osobno ustaw Armor HUD, FPS, CPS, Combo i efekty mikstur. Pozycje zapisują się w konfiguracji moda.
⇧Prawy Shift / P — otwiera menu ustawień. H — ukrywa lub pokazuje HUD. Edytor pozycji znajdziesz w zakładce HUD.
Minecraft Java 1.21.1Fabric LoaderFabric APIJava 21
Pobierz PvP HUD 2.0.15 ↗Instrukcja instalacji ↗

To osobny JAR moda Fabric 1.21.1, nie instalator launchera. Wymagane są Fabric API i Java 21+. Synchronizacja układu z launchera do moda obsługuje skalę 75–100%; większa skala podglądu nie jest eksportowana.

Podgląd interaktywny: przeciągnij kafelki myszką lub palcem, aby zmienić ich pozycję; strzałki przesuwają zaznaczony kafelek. To wyłącznie demonstracja na stronie. W grze edytor otworzysz prawym Shiftem → HUD → PRZESUŃ KAFELKI.

03 / JEDEN MOTYW

Ciemny Łupek. Wspólny wygląd launchera i strony.

Grafitowe panele, błękitno-stalowe akcenty, nowa grafika świata blokowego i czytelne ikony. Bez zbędnego przełączania motywów.

Paleta Slate

Tło #1E2022, panele #282C30, akcent #52616B, tekst #F0F5F9.

Czytelne ikony

Jeden zestaw kontrastowych ikon, bez jasnych kwadratowych podkładów i z wyraźnym stanem aktywnej funkcji.

Więcej miejsca

Oddzielne kategorie modów, paczek, shaderów, datapacków i resourcepacków.

Nowa grafika koncepcyjna w motywie Ciemny Łupek, nie zrzut ekranu działającego programu.
