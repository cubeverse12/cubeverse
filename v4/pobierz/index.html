Co zmieniono w RC23 UI26?

Przed startem gry launcher wykrywa rozpoznane brakujące biblioteki Fabric i dobiera zgodne wersje z Modrinth. RC23 UI26 sprawdza alternatywne zestawy, maksymalnie 24 próby pobrania kandydatów. Nie nadpisuje istniejących modów. Nieznane zależności wymagają ręcznej instalacji.

Pięć etapów uruchamiania, poprawki obsługi błędów, zabezpieczenia kopii i importu paczek, równe ikony 22 × 22 px oraz dopasowanie okna do monitorów.

RC23 UI26 udoskonala walidację wersji i loaderów, kontrolki, pamięć podręczną ikon, kamerę Skin Studio, podgląd PvP oraz diagnostykę uruchamiania. To wydanie źródłowe do zamkniętych testów Windows, nie podpisany instalator EXE/MSIX.

Logowanie Microsoft, start gry, pobieranie online i GUI Windows wymagają testów. CurseForge wymaga autoryzowanego klucza API, aktualizator wymaga klucza wydawcy, a właściwy JAR PvP HUD nie jest dołączony. Publiczna dostępność UI26 w GitHub Releases nie jest potwierdzona.

Instrukcja testów RC23 UI26
Wcześniejsze poprawki R2–R7 — historia zmian
Poprawki źródeł 1.56.19 R2 i R3

R2 naprawia README, nagłówek instalatora i skrypt kontroli plików. R3 dodaje 04_DIAGNOZA_15619_R3.bat — bezpieczny raport startu bez haseł, tokenów i pełnych ścieżek użytkownika.

W R3 przeszło 39 testów offline, a 1405 sum SHA-256 jest zgodnych. Nie jest to test uruchomienia gry na Windows. Pełna paczka R3 jest dostępna w rozmowie z dnia 17.11.2026; na GitHub Releases pobieraj tylko faktycznie opublikowane wydania.

Kontrola importów — 1.56.19 R4

R4 rozszerza sprawdzanie lokalnych modułów programu. 02_SPRAWDZ_15619.bat wykrywa statycznie brakujące nazwy funkcji i klas w pięciu kluczowych plikach interfejsu. Dodatkowo dostępny jest 05_SPRAWDZ_IMPORTY_15619_R4.bat.

Pakiet R4 został przekazany w rozmowie. Publiczną dostępność wydania potwierdzaj osobno w GitHub Releases. Kontrola nie uruchamia Minecrafta, Qt ani logowania Microsoft.

R5 — ikony konturowe i pełna analiza importów

W paczce źródłowej 1.56.19 R5 poprawiono odczyt ikon konturowych, w tym plus i server-check. Dodano też skrypt 06_SPRAWDZ_ZASOBY_15619_R5.bat, który sprawdza grafikę SVG/PNG i lokalne importy bez uruchamiania gry.

Pakiet R5 jest udostępniony w rozmowie, nie jako potwierdzony publiczny instalator. W GitHub Releases sprawdzaj rzeczywiście dostępne wydania.

Archiwalna makieta wyglądu: 1.56.19 R7

R6 naprawiała przycinanie grafiki cyberwilka w nagłówku. R7 przebudowuje jedynie układ ekranu GRAJ w Qt, zachowując podłączone przyciski i pola profilu. Do paczki dołączono test wizualny 08_SPRAWDZ_WYGLAD_15619_R7.bat.

Kontrole offline nie dowodzą, że gra lub logowanie działają na komputerze Windows. Paczka R7 została przygotowana w rozmowie, lecz nie potwierdzono jej publikacji w GitHub Releases. Zobacz podgląd układu R7.

Bezpieczeństwo i logowanie

Nie wyłączaj Microsoft Defender ani Smart App Control. Logowanie Microsoft wymaga prawidłowej rejestracji aplikacji wydawcy; sam Client ID nie gwarantuje działania. Nie przesyłaj nikomu haseł, tokenów ani kodów urządzenia.
