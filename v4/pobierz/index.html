Pobierz MINEVORA bez zgadywania wersji.

Wersja robocza MINEVORA 1.48.2 ma nowy interfejs BlockForge i grafitowo-niebieską kolorystykę. Nie ma jednak potwierdzenia, że jest dostępna jako publiczne wydanie GitHub. Sprawdź numer pliku, który pobierasz.

Publiczne wydania

Pliki do pobrania

Lista GitHub Releases zawiera wyłącznie faktycznie opublikowane pliki. Wybierz właściwą wersję Windows i przeczytaj jej README przed instalacją.

Otwórz GitHub Releases ↗

Nie udostępniamy fikcyjnego linku do ZIP 1.48.2 ani niesprawdzonego pliku EXE.

Projekt testowy 1.43

Co zmieniono?

Kontrola konta, wersji gry i loadera przed uruchomieniem, bezpieczniejszy zapis serwerów oraz raport diagnostyki w Ustawieniach.

Do potwierdzenia: logowanie Microsoft, uruchomienie Minecrafta na Windows 11 i PvP HUD w grze. Dołączony mod jest przeznaczony dla Fabric 1.21.1.

INSTALACJA

Trzy proste kroki.

KROK 01

Wybierz wydanie

Otwórz GitHub Releases i sprawdź numer dostępnej wersji. Nie pomyl kodu źródłowego z instalatorem.

KROK 02

Rozpakuj ZIP

Rozpakuj archiwum do osobnego folderu. Zachowaj README i przejrzyj wymagania systemowe.

KROK 03

Uruchom skrypt

Wykonaj instrukcję z README danego wydania. W paczce 1.48.2 uruchom INSTALUJ.bat, a następnie START_WINDOWS.bat.

Bezpieczeństwo i logowanie

Nie wyłączaj Microsoft Defender ani Smart App Control. Logowanie Microsoft wymaga prawidłowej rejestracji aplikacji wydawcy; sam Client ID nie gwarantuje działania. Nie przesyłaj nikomu haseł, tokenów ani kodów urządzenia.
