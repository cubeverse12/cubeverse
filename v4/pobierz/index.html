Pobierz MINEVORA bez zgadywania wersji.

MINEVORA 1.56.19 R9 BETA zachowuje wygląd Graphite Green i ekran GRAJ z R7. W R9 poprawiono testy uruchamiania Minecrafta oraz weryfikację kompletności plików instalacji. To paczka z kodem Pythona i skryptami Windows, niegotowa jeszcze do publikacji jako wersja stabilna. R9 nie została opublikowana w GitHub Releases.

Publiczne wydania

Pliki do pobrania

GitHub Releases zawiera publicznie opublikowane paczki. W dniu 17 listopada 2026 r. najnowszą potwierdzoną wersją jest 18.3.7 — Neon Desktop (28 października 2026 r.). Nie jest to R9. Przed pobraniem sprawdź nazwę i opis pliku.

Otwórz GitHub Releases ↗

R9 BETA jest dostępna w rozmowie z 17.11.2026 jako ZIP źródeł. Nie ma gotowego EXE/MSIX ani publicznego wydania R9 w GitHub Releases.

Projekt testowy 1.56.19 R9 BETA

Co zmieniono w R9?

Poprawiono 9 testów uruchamiania Minecrafta i 11 testów blokad wspólnej instalacji. Dodano kontrole brakujących i uszkodzonych plików gry. R9 nie zmienia mechanizmu uruchamiania Minecrafta ani wyglądu ekranu GRAJ z R7.

Dołączone zostały dwa warianty źródeł: lżejsza BETA dla testerów oraz pełne źródła z historią. Podgląd wyglądu pozostaje makietą na podstawie kodu Qt R7. Nadal wymagane są testy PySide6, konta Microsoft, startu Minecrafta i PvP HUD w Windows.

INSTALACJA

Trzy proste kroki.

KROK 01

Wybierz wydanie

Jeśli pobierasz publiczne wydanie, użyj GitHub Releases. Wersja rozwojowa R9 została przekazana osobno w rozmowie; nie myl jej z publiczną 18.3.7.

KROK 02

Rozpakuj ZIP

Rozpakuj archiwum do osobnego folderu. Zachowaj README i przejrzyj wymagania systemowe.

KROK 03

Uruchom skrypt

Wykonaj instrukcję z README danego wydania. W paczce testowej 1.56.19 R9 uruchom 01_INSTALUJ_15619.bat, potem 02_SPRAWDZ_15619.bat, opcjonalnie 09_TESTY_STARTU_R9.bat i na koniec 03_URUCHOM_15619.bat. Inne wydania mogą mieć inne skrypty — sprawdź README.

MINEVORA 1.56.19 R9 BETA — pliki dla testerów, nie publiczne wydanie

Dostępne w rozmowie: uproszczona BETA, pełne źródła oraz komplet obydwu wariantów. BETA ma 562 zweryfikowane pliki, pełne źródła 1435; archiwa sprawdzono pod kątem integralności. To źródła Python, nie samodzielny instalator Windows.

Testy: 94 aktualne testy offline zaliczone. Historyczny zestaw 1024 testów nadal wykazuje 218 niepowodzeń i 5 błędów. Na Windows należy jeszcze sprawdzić okno Qt, logowanie, instalację i uruchomienie Minecrafta.

Przejdź do instrukcji testowania R9. Nie wyłączaj zabezpieczeń Windows i nie udostępniaj danych konta.

Wcześniejsze poprawki R2–R7 — historia zmian
Poprawki źródeł 1.56.19 R2 i R3

R2 naprawia README, nagłówek instalatora i skrypt kontroli plików. R3 dodaje 04_DIAGNOZA_15619_R3.bat — bezpieczny raport startu bez haseł, tokenów i pełnych ścieżek użytkownika.

W R3 przeszło 39 testów offline, a 1405 sum SHA-256 jest zgodnych. Nie jest to test uruchomienia gry na Windows. Pełna paczka R3 jest dostępna w rozmowie z dnia 17.11.2026; na GitHub Releases pobieraj tylko faktycznie opublikowane wydania.

Kontrola importów — 1.56.19 R4

R4 rozszerza sprawdzanie lokalnych modułów programu. 02_SPRAWDZ_15619.bat wykrywa statycznie brakujące nazwy funkcji i klas w pięciu kluczowych plikach interfejsu. Dodatkowo dostępny jest 05_SPRAWDZ_IMPORTY_15619_R4.bat.

Pakiet R4 został przekazany w rozmowie. Publiczną dostępność wydania potwierdzaj osobno w GitHub Releases. Kontrola nie uruchamia Minecrafta, Qt ani logowania Microsoft.

R5 — ikony konturowe i pełna analiza importów

W paczce źródłowej 1.56.19 R5 poprawiono odczyt ikon konturowych, w tym plus i server-check. Dodano też skrypt 06_SPRAWDZ_ZASOBY_15619_R5.bat, który sprawdza grafikę SVG/PNG i lokalne importy bez uruchamiania gry.

Pakiet R5 jest udostępniony w rozmowie, nie jako potwierdzony publiczny instalator. W GitHub Releases sprawdzaj rzeczywiście dostępne wydania.

Najnowsza wersja wyglądu: 1.56.19 R7

R6 naprawiała przycinanie grafiki cyberwilka w nagłówku. R7 przebudowuje jedynie układ ekranu GRAJ w Qt, zachowując podłączone przyciski i pola profilu. Do paczki dołączono test wizualny 08_SPRAWDZ_WYGLAD_15619_R7.bat.

Kontrole offline nie dowodzą, że gra lub logowanie działają na komputerze Windows. Paczka R7 została przygotowana w rozmowie, lecz nie potwierdzono jej publikacji w GitHub Releases. Zobacz podgląd układu R7.

Bezpieczeństwo i logowanie

Nie wyłączaj Microsoft Defender ani Smart App Control. Logowanie Microsoft wymaga prawidłowej rejestracji aplikacji wydawcy; sam Client ID nie gwarantuje działania. Nie przesyłaj nikomu haseł, tokenów ani kodów urządzenia.
