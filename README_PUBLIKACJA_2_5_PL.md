# MINEVORA — strona WWW 2.5

Wgraj zawartość tego folderu bezpośrednio do katalogu głównego repozytorium GitHub Pages. Zachowaj pliki `index.html`, `unified-2-5.css`, `minevora-reference.js` i katalog `assets/`. W GitHub Pages wybierz publikację z odpowiedniej gałęzi i katalogu `/ (root)`.

Funkcje w osobnych zakładkach: Start (#home), Poradnik (#poradnik), Minigry (#minigames), PvP (#pvp), Rankingi (#rankings), Sklep (#sklep), O projekcie (#odkrywaj), Konto (#account), Pobieranie (#download). Sklep i serwer nadal są w przygotowaniu, rankingi demonstracyjne.

Strona WWW nie uruchamia gry; do tego potrzebny jest launcher Windows.
